# 👋 Hi, I'm Rodrigo

Control and Automation Engineering student at **UTFPR** (Curitiba, Brazil — graduating Dec 2026) and **Embedded Systems and IoT Developer** at **Mify Smart Factory**.

I work where hardware meets software: from the board schematic to firmware running in the field, all the way to cloud communication.

### 🔧 What I do

- **Embedded firmware** with ESP-IDF and FreeRTOS
- **Industrial IoT devices**: data collection, 4G/Wi-Fi connectivity, fleet OTA updates and hardening
- **Hardware design**: schematics, component selection and board reviews

### 🚀 Featured projects

| Project | Description |
|---|---|
| **Smartband with embedded AI** (thesis) | Wearable wristband with on-device AI for fall detection |
